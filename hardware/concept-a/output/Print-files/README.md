# Print files

Import the STL files in Bambu Studio. Units are millimeters. Each file keeps its checked print orientation.

Required: 38 installed pieces (17 White, 21 Black). Optional: 19 gauges, test pieces, and retention coupons (14 White, five Black).

Start with Optional coupons before printing Required pieces. Follow [the assembly guide](../../CASING_ASSEMBLY.md) and [the offline viewer](../assembly/robot-viewer.html). Native projects with P1S settings are in [the Bambu folder](../bambu/).

Use the P1S, 0.4 mm nozzle, PLA, 0.2 mm layers, three walls, and automatic tree supports. Inspect supports before printing. Physical fit and retention remain unverified.
